02 / Decisions

  1. DEC-01 Tests first, upgrade second

    The Rails monolith had 26% test coverage, and its GraphQL API served internal admin apps, client websites, and mobile apps. An upgrade could break any of them without a single test failing.

    ✕ Turned down

    Upgrade first, then fix what breaks in production

    ✓ Chose

    Grew an RSpec and VCR safety net from 26% to 77% coverage over six months, then upgraded Rails 7.0 → 7.2 and fixed the transaction rollback, encryption, and dependency issues the tests caught.

    Cost
    A slower start. Months of test work came before the upgrade itself.
    Proof
    Rails 7.0 → 7.2 shipped, up-to-date backend dependencies went from 26% to 83%, and production Sentry errors fell by 73%.

03 / What I did
