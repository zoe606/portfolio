themx

Gives AI coding agents the design context they need, so the UI they build follows one consistent theme.

2026 — now · 7 months Website ↗GitHub ↗

02 / What I did

  1. 01

    Built themx to give AI coding agents design context: a chosen theme from a catalog of 38 becomes ready-to-use prompts, so the UI an agent builds follows one consistent design.

  2. 02

    A prompt builder combines the theme with the project brief, framework, and UI library, then exports a design bundle with DESIGN.md, an AGENTS.md section, and CSS and JSON tokens.

  3. 03

    Live previews render each theme on sample dashboard, product, and portfolio pages with daisyUI and shadcn/ui components.

  4. 04

    Shipped as a static Astro site with Preact islands, Tailwind CSS 4, and Vitest and Playwright tests.
